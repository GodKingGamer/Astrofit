# AstroFit Studio

Ứng dụng bản đồ sao cá nhân, hợp đôi nhiều người và vận hạn, viết bằng lời dễ hiểu.
Cài được lên điện thoại như một app (PWA), dùng được cả khi không có mạng.

**Mở app:** https://godkinggamer.github.io/Astrofit/

- Android (Chrome): bấm **Cài app** ở cuối trang, hoặc menu ⋮ → *Cài đặt ứng dụng*.
- iPhone (Safari): nút Chia sẻ → *Thêm vào MH chính*.
